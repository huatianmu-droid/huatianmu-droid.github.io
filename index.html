Garment measurement records

Open the garment measurement-method checklist

Start with the method, not the size label

A recorded width has limited meaning when its endpoints and conditions are missing. A body circumference, a garment laid flat and a stretched garment are different observations. A shared unit such as centimetres does not make those methods equivalent. Record which object was measured, the selected variant, the endpoints and whether the material was relaxed or stretched.

Use the checklist beside your own reference garment and the seller's actual chart. Leave an unknown method unanswered rather than selecting an answer because the numbers look plausible. The tool reports the state of the fields you provide; it does not inspect a photograph, verify a seller's statement or determine that an item will fit.

Keep a useful decision record

Retain the original source and check date alongside each measurement. If you receive a correction, preserve the earlier observation as superseded and explain what changed. Do not combine details from two colours or sizes into one apparently complete record. A clear unresolved question is a useful result when it identifies what you need to ask next.

The interactive checklist and its explanation are maintained in one place, linked above. This entry page provides navigation and publishing information; it does not duplicate the tool or collect measurement entries.
